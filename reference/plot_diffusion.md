# Plot interval-specific diffusion rates

Plot interval-specific diffusion rates

## Usage

``` r
plot_diffusion(ibmfit, probs = c(0.025, 0.5, 0.975))
```

## Arguments

- ibmfit:

  A locally adaptive `ibmfit`.

- probs:

  Lower, center, and upper posterior probabilities.

## Value

A ggplot object.
